Syarat & Ketentuan

1. Pendahuluan

Selamat datang di MediLearn Education. Dengan mengakses atau menggunakan aplikasi ini, Anda dianggap telah membaca, memahami, dan menyetujui seluruh syarat dan ketentuan yang berlaku.

2. Penggunaan Aplikasi

Aplikasi ini dirancang sebagai alat bantu belajar (viewer) untuk modul kedokteran dan kesehatan. Pengguna dilarang menyalahgunakan aplikasi untuk tindakan ilegal, plagiarisme, atau distribusi konten tanpa izin.

3. Disclaimer Medis

Materi yang terdapat dalam aplikasi ini hanya untuk tujuan pendidikan kedokteran.

Aplikasi ini dibuat khusus untuk mahasiswa dan profesional kedokteran, tidak untuk masyarakat awam sebagai integritas akademik dan keprofesian.

4. Hak Kekayaan Intelektual

Seluruh konten modul yang diunggah adalah tanggung jawab pengguna. MediLearn hanya menyediakan platform (viewer). Pastikan Anda memiliki hak akses terhadap file modul yang Anda unggah.

5. Keamanan & Data

Data modul disimpan secara lokal di perangkat Anda (IndexedDB Browser). Kami tidak mengunggah data Anda ke server cloud eksternal, menjamin privasi penuh data pembelajaran Anda. Harap lakukan Backup data secara berkala.

6. Perubahan Ketentuan

MediLearn berhak mengubah syarat dan ketentuan ini sewaktu-waktu tanpa pemberitahuan sebelumnya demi peningkatan layanan.
